# Review: 2026-10-10

## What the project does

A Streamlit app that turns Japanese VGC team reports (note.com, Hatena Blog, liberty-note.com and similar sites) into English for players who don't read Japanese: a Showdown paste, EV spreads with the author's reasoning, strategy notes and a full translation. Gemini does the analysis with each user's own API key. The deployment target is Streamlit Community Cloud.

## Live findings

- **No hosted URL.** There is no GitHub homepage, and the only `streamlit.app` link in the repo was the placeholder `your-streamlit-app.streamlit.app`. I couldn't check a live deployment.
- **Model.** The code hardcoded `gemini-2.5-flash`. On 2026-10-10, Google's deprecations page says the 2.5 models "are not deprecated and will continue to be served until further notice" and recommends 3.x Flash for new projects. Some third-party posts report a 16 Oct 2026 shutdown date, and there are forum reports of 404s on 2.5-flash in July 2026. I couldn't confirm the model from a real call because the API key in this environment was rejected as invalid. The model id is now configurable (`GEMINI_MODEL`), so a retirement needs a config change, not a code change.
- **Fetcher works.** Read-only GETs of three real articles all returned the article body, including the 努力値 (EV) lines: two note.com posts through note's JSON API, about 2.5k and 3.9k characters, and one liberty-note.com post at about 4.5k characters.
- **README and compliance docs were fiction.** They described a FastAPI backend (`app/backend/*`) with an allowlist, robots.txt checks, PII redaction, Redis rate limiting and an age gate. All of that was deleted in `e0edf6d`. There is no FastAPI app, so the "is the backend dead weight" question is already settled: it's gone.
- **The test suite couldn't run.** `pytest` aborted before collecting anything: the `--cov=app` addopts needed pytest-cov, and two test files imported modules that no longer exist and called `sys.exit(1)` at import time. One remaining test returned a bool instead of asserting, which hid a real failure: "Iron Shaman" was no longer corrected to Iron Valiant.

## Changes made

1. **SSRF guard.** User URLs, every redirect hop, and image URLs scraped from the page must be `http(s)` and resolve to public IPs. Before this, the app would fetch `http://169.254.169.254/...` or `localhost`.
2. **No retries on API errors.** Auth, quota and rate-limit errors used to be retried with two more Gemini calls, and the user then saw a generic "Analysis failed" instead of the quota or key message. They now surface on the first failure.
3. **Showdown paste is importable.** `Not specified` placeholders no longer leak into lines like `@ Not specified`, `Tera Type: Not specified` or `Not specified Nature`. EVs fall back to the `ev_spread` dict when the string is missing. The paste is shown in an `st.code` block with a copy button, replacing an inline-JS `onclick` button.
4. **Result cache.** Successful analyses are cached in memory per (model, input), up to 100 entries, so re-analysing the same URL costs no Gemini call. Cache hits are labelled in the UI.
5. **`GEMINI_MODEL`** can be set as an env var or Streamlit secret. The default is `gemini-2.5-flash`.
6. **Data fixes.** Name corrections added for the hallucinations the prompt warns about: Iron Shaman, Bishop and Black Scarf. Fixed アクアブレイク → Liquidation (it was mapped to Aqua Tail) and removed a duplicate dictionary key.
7. **Scraper.** It no longer advertises `br` encoding, which `requests` can't decode unless brotli is installed.
8. **Tooling.** The 300-line pyproject for the deleted `app` package is replaced with pytest and ruff config. Added `requirements-dev.txt`. Removed the unused `aiohttp`, `lxml` and `urllib3` from requirements. Deleted the two dead test scripts and the unused committed `src/vgc_analyzer.db`. Added offline tests in `tests/test_safety_and_export.py`.
9. **Docs.** Rewrote the README to match reality, added a "historical" banner to `COMPLIANCE_CHECKLIST.md`, and trimmed `.env.example`.

Verification: `pytest -q` gives 15 passed. `ruff check .` is clean. A Streamlit `AppTest` run of `app.py`, both empty and with a rendered result, raised no exceptions on Streamlit 1.65.0. All of this also passed in a fresh venv built from `requirements-dev.txt`.

## Remaining suggestions (ranked)

| # | Suggestion | Effort |
|---|---|---|
| 1 | **Use Gemini structured output.** Pass a `response_schema` (Pydantic model for the team) instead of describing JSON in the prompt. That removes most of the parse-recovery code in `analyzer.py` (~1.4k lines) and the "partial recovery" UI paths. | M |
| 2 | **Run a real end-to-end check with a valid key**, and try `gemini-3.x-flash` via `GEMINI_MODEL`. Promote it to the default if output quality holds. | S |
| 3 | **Treat page text as untrusted (prompt injection).** Wrap the article in clear delimiters and tell the model to ignore instructions inside it. Rendering is already HTML-escaped, so the realistic risk is a manipulated summary, not XSS. | S |
| 4 | **Image analysis cost.** It sends up to 10 images, one Gemini call each, after the text call, using the user's quota. Cap it at about 3 and skip it when the text already has six full EV spreads. | S |
| 5 | **Decide on crawling policy.** The allowlist and robots.txt checks are gone. With bring-your-own-key the Gemini ToS concern is smaller, but a `urllib.robotparser` check before fetching is about 10 lines and is polite to the blogs being read. | S |
| 6 | **Dead code.** Remove `Config.get_google_api_key`/`init_config` (keys only come from the sidebar), unused helpers in `utils.py`/`image_analyzer.py`, and the `.claude/` agent files if unused. Remove `packages.txt` (libgl etc.) if nothing needs OpenCV. Also update `docs/CLAUDE.md` and `docs/ARCHITECTURE.md`, which still describe the file layout from before `e0edf6d`. | M |
| 7 | **Streamlit API drift.** `use_container_width=` is deprecated in favour of `width="stretch"` (11 call sites). `config.toml` hides deprecation warnings (`suppressDeprecationWarnings = true`), so breakage will arrive unannounced. | S |
| 8 | **Pin dependencies.** Upper-bound or lock `streamlit` and `google-genai` so a Cloud redeploy can't silently pull a breaking major version. | S |
| 9 | **Content cap.** Text is truncated to 30k characters before the Gemini call. That is fine for typical reports, but very long multi-team articles lose the tail silently. Show a notice when truncation happens. | S |
| 10 | **Persistent cache.** The in-memory cache is lost on every Cloud restart. A small on-disk store keyed by URL would make repeat lookups free across restarts. | M |
